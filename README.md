# WebCMaker

Статический сайт-портфолио на HTML, CSS и JavaScript.

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер из этой папки:

```powershell
python -m http.server 8000
```

Затем перейдите на `http://localhost:8000`.

## Страницы

- `index.html` — главная, услуги, процесс, FAQ и CTA.
- `services.html` — подробности услуг, рамки проектов, сроки и правила правок.
- `projects.html` — честные слоты под будущие кейсы.
- `brief.html` — подробный бриф на проект.

## Где менять содержание

Тексты на трёх языках находятся в `content.js`. Стили — в `styles.css`, поведение и шаблоны страниц — в `app.js`.

## Перед публикацией

- Форма открывает черновик письма на `webcmaker@gmail.com`; посетитель отправляет его из своей почтовой программы. Для автоматического приёма заявок понадобится подключить почтовый сервис или backend.
- Структура сайта статическая. Панель CMS можно подключить после выбора хостинга и репозитория; сейчас контент лежит в отдельном файле и не зависит от разметки.
- Добавьте рабочие контактные данные перед публикацией.
- Добавьте реальные кейсы и отзывы только после получения разрешения на публикацию.
- Сроки на сайте указаны как ориентировочные.
- Указание «5 лет опыта» не добавлено: используйте его только если это подтверждённый срок.
