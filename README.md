# WebCMaker

Портфолио на обычных HTML, CSS и JavaScript. Для просмотра и публикации на GitHub Pages не нужны зависимости или сборка.

## Страницы

- `index.html` — главная, работы, услуги, процесс и FAQ.
- `projects.html` — два учебных концепта: TERRA и FORMA.
- `services.html` — форматы сайтов, сроки и условия работы.
- `brief.html` — бриф и контактная почта `webcmaker@gmail.com`.

Концепты открываются отдельно: `projects/terra-coffee/` и `projects/forma-construction/`. Это демонстрационные работы, а не коммерческие кейсы.

TERRA — сайт кофейни с поиском и категориями меню, составом напитков и локальным планировщиком визита. FORMA — сайт строительной компании с досье проектов и конфигуратором состава работ. Главные кнопки работают внутри концептов; ссылка на портфолио вынесена в демонстрационную панель или подвал. План визита и черновик строительного запроса не отправляют данные и не оформляют реальные заявки.

## Просмотр и публикация

Откройте `index.html` в браузере или раздайте папку любым статическим сервером. Для GitHub Pages публикуйте содержимое этой папки из корня выбранной ветки. Ссылки между страницами относительные и работают в каталоге репозитория.

Основные изображения, SVG и шрифт лежат в корне рядом со страницами. Manrope подключён локально через компактный `manrope-variable.woff2` с поддержкой RU/UK/EN; исходный TTF сохранён, лицензия SIL Open Font License 1.1 — в `manrope-license.txt`. Обложки используют WebP и `srcset`, изображения FORMA и её шрифты загружаются локально.

Логотип хранится в `brand-mark.svg`, иконка вкладки — в `favicon.svg`. Оба используют один знак из переплетённых лент.

Анимации появления, наведения, раскрытия FAQ и отдельных деталей SVG учитывают системную настройку уменьшения движения. Основное содержимое видно и при отключённых эффектах.

Появление блоков начинается до входа в экран. На телефоне нет каскадных задержек; при быстром скролле уже видимые блоки пропускают эффект, чтобы содержимое не мигало.

## Редактирование

- `content.js` — тексты на русском, украинском и английском.
- `app.js` — структура страниц и поведение.
- `styles.css` — оформление и адаптация под разные экраны.

После изменения `app.js` или `content.js` выполните:

```powershell
node prerender.cjs
```

Скрипт использует только встроенные модули Node.js и обновляет начальную HTML-разметку четырёх страниц. Благодаря этому основное содержание доступно и без JavaScript. Node.js нужен только для обновления разметки, а не для просмотра или размещения готового сайта.

## Бриф и состав услуги

Форма отправляет бриф через [Formspree](https://formspree.io/) без перехода на другой сайт. Публичный endpoint `https://formspree.io/f/xyeejarz` предоставлен владельцем; получатель `webcmaker@gmail.com` настраивается в аккаунте Formspree. Секретный API-ключ в коде не нужен.

JavaScript отправляет JSON с `Accept: application/json`, показывает результат по HTTP-статусу, блокирует повторный запрос во время отправки и завершает ожидание через 15 секунд. Ответы сохраняются при ошибке. Без JavaScript или fetch работает обычный POST на тот же endpoint с экраном благодарности Formspree. Копирование также доступно.

Данные обрабатывает Formspree, что указано под формой со ссылкой на политику сервиса. Успешный HTTP-ответ подтверждает приём заявки сервисом, а не доставку уведомления в Gmail. Получение тестового брифа проверяется в почте и разделе Submissions аккаунта Formspree.

Публичный `formEndpoint` и тема письма заданы в `app.js`. При смене формы обновите endpoint и выполните `node prerender.cjs`. Получателя и уведомления меняйте в панели Formspree.

WebCMaker создаёт лендинги, сайты компаний и интернет-магазины, обновляет готовые сайты. В проект можно включить каталог, корзину, подключение онлайн-оплаты через платёжный сервис, домен, хостинг и публикацию. Состав работ и расходы сторонних сервисов согласуются до начала проекта; после завершения заказчик получает файлы и исходный код.
