# WebCMaker

Портфолио на обычных HTML, CSS и JavaScript. Для просмотра и публикации на GitHub Pages не нужны зависимости или сборка.

## Страницы

- `index.html` — главная, работы, услуги, процесс и FAQ.
- `projects.html` — два учебных концепта: TERRA и FORMA.
- `services.html` — форматы сайтов, сроки и условия работы.
- `brief.html` — бриф и контактная почта `webcmaker@gmail.com`.

Концепты открываются отдельно: `projects/terra-coffee/` и `projects/forma-construction/`. Это демонстрационные работы, а не коммерческие кейсы.

## Просмотр и публикация

Откройте `index.html` в браузере или раздайте папку любым статическим сервером. Для GitHub Pages публикуйте содержимое этой папки из корня выбранной ветки. Ссылки между страницами относительные и работают в каталоге репозитория.

Основные изображения, SVG и шрифт лежат в корне рядом со страницами. Manrope подключён локально через `manrope-variable.ttf`; лицензия SIL Open Font License 1.1 сохранена в `manrope-license.txt`.

Логотип хранится в `brand-mark.svg`, иконка вкладки — в `favicon.svg`. Оба используют один знак из переплетённых лент.

Анимации появления, наведения, раскрытия FAQ и отдельных деталей SVG учитывают системную настройку уменьшения движения. Основное содержимое видно и при отключённых эффектах.

## Редактирование

- `content.js` — тексты на русском, украинском и английском.
- `app.js` — структура страниц и поведение.
- `styles.css` — оформление и адаптация под разные экраны.

После изменения `app.js` или `content.js` выполните:

```powershell
node prerender.cjs
```

Скрипт использует только встроенные модули Node.js и обновляет начальную HTML-разметку четырёх страниц. Благодаря этому основное содержание доступно и без JavaScript. Node.js нужен только для обновления разметки, а не для просмотра или размещения готового сайта.

## Бриф и состав услуги

Форма отправляет бриф обычным POST-запросом через [FormSubmit](https://formsubmit.co/) на `webcmaker@gmail.com`. Копирование оставлено как запасной вариант. JavaScript и собственный сервер для отправки не нужны.

Перед приёмом заявок владелец почты должен активировать форму: отправить короткий тестовый бриф с опубликованной страницы, открыть письмо FormSubmit в Gmail и нажать ссылку подтверждения. Если письма нет, проверьте «Спам». Затем отправьте ещё один тестовый бриф и проверьте его получение. До подтверждения доставка на почту не проверена.

Защита CAPTCHA включена по умолчанию; скрытое поле `_honey` дополняет её. Данные обрабатывает FormSubmit, что указано под формой со ссылкой на политику сервиса. Пароли, ключи и конфиденциальные документы через бриф отправлять не следует. После обработки сервис возвращает посетителя на `brief.html?sent=1#form-status`; это подтверждение обработки, а не гарантированной доставки в Gmail.

Получатель, тема и абсолютные URL возврата заданы в `app.js`. При переносе сайта измените `_url` и `_next`, затем выполните `node prerender.cjs`.

WebCMaker создаёт лендинги, сайты компаний и интернет-магазины, обновляет готовые сайты. В проект можно включить каталог, корзину, подключение онлайн-оплаты через платёжный сервис, домен, хостинг и публикацию. Состав работ и расходы сторонних сервисов согласуются до начала проекта; после завершения заказчик получает файлы и исходный код.
